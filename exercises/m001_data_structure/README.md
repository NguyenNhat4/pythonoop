# m001_data_structure

Bo bai tap cau truc du lieu theo OOP, tu de -> kho. Moi file la mot bai, co docstring mo ta yeu cau va goi y I/O. Ban tu viet main de tu test nhanh trong terminal.

Thu tu goi y:
- ex01_stack.py: Ngan xep co ban
- ex02_stack_min.py: MinStack lay min O(1)
- ex03_queue_two_stacks.py: Queue bang 2 Stack
- ex04_queue_circular.py: Queue vong co dinh
- ex05_singly_linked_list.py: DSLK don
- ex06_doubly_linked_list.py: DSLK kep + reverse
- ex07_deque.py: Deque 2 dau
- ex08_dynamic_array.py: Mang dong resize
- ex09_hash_map.py: HashMap chaining + resize
- ex10_set_ops.py: Set tren HashMap + hop/giao/hieu
- ex11_binary_heap.py: Heap nhi phan
- ex12_priority_queue.py: Hang doi uu tien
- ex13_bst.py: Cay BST co ban
- ex14_trie.py: Trie, prefix
- ex15_graph_adjlist.py: Graph danh sach ke, BFS/DFS/shortest path
- ex16_toposort.py: Topological sort cho DAG
- ex17_lru_cache.py: LRU cache O(1)

Luu y:
- Giu interface dung nhu mo ta trong docstring.
- Dung `raise NotImplementedError` da dat san lam moc hoan thanh.
